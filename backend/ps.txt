We need to implement the Therapist Recommendation ML module for our
ISE (Interactive Skills Enhancer) project.

IMPORTANT:
- This is an educational/support recommendation system.
- It must NOT diagnose ASD, ID, emotional disorders, or any medical condition.
- It must NOT replace a qualified therapist or clinical assessment.
- The output should be a "recommended support area" for the parent/educator.
- Do not use facial recognition or facial emotion detection.
- Do not use the child's video recording as a clinical diagnostic signal.
- Keep the implementation simple and reliable for an 8-hour hackathon.
- Do not modify unrelated existing modules.

==================================================
OBJECTIVE
==================================================

Build and train a real ML model that recommends an appropriate
support/therapy area based on the child's accumulated learning data.

The model should learn from measurable learning indicators such as:

- communication score
- social interaction score
- empathy score
- emotion recognition score
- response accuracy
- response time
- mistake rate
- repeated mistake count
- improvement trend
- number of completed sessions
- current difficulty level

The model output should be a SUPPORT AREA, not a medical diagnosis.

Suggested output classes:

0 = Speech & Communication Support
1 = Social Skills Support
2 = Emotional/Social Understanding Support
3 = Behavioral/Functional Skills Support

Keep these labels configurable so they can be changed later.

==================================================
RECOMMENDATION API
==================================================

Integrate the trained model into the existing FastAPI backend.

Create an endpoint:

GET /children/{child_id}/therapist-recommendation

The endpoint should:

1. Fetch the child's learning history from Firebase.
2. Calculate the required ML features.
3. Load the trained model.
4. Generate the predicted support area.
5. Return the recommendation.
6. Return confidence/probability if supported by the model.
7. Return the main contributing indicators.
8. Return a clear disclaimer that this is a support recommendation
   and not a medical diagnosis.

Example response:

{
  "child_id": "child_001",
  "recommended_support_area": "Speech & Communication Support",
  "confidence": 0.84,
  "key_indicators": {
      "communication_score": 42,
      "social_interaction_score": 61,
      "emotion_recognition_score": 70,
      "improvement_rate": 0.08
  },
  "reason": "Communication performance has remained relatively low
             across recent learning sessions.",
  "disclaimer": "This is an educational support recommendation and
                  not a clinical diagnosis."
}
