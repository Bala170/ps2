# ISE — Interactive Skills Enhancer

An educational web app for children with ASD and intellectual disabilities.

## Tech Stack
- React 19 + TypeScript
- Vite 8
- Tailwind CSS v4
- Recharts (analytics)

## Screens
1. **Onboarding** — Name, age drum-roller, interests card deck, skill picker
2. **Dashboard** — Animated board-game trail with live sky background
3. **Lesson** — Interactive scenario with 4-option answer cards
4. **Feedback** — Confetti celebration or learning moment
5. **Parent Portal** — Professional analytics dashboard with charts

## Getting Started
```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173)
